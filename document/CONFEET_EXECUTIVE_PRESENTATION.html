Data Consistency

Deterministic FIFO Message Ordering

Monotonic 64-bit sequence counters backed by Kafka event streams and MongoDB.

Confeet

Why Monotonic Sequencing Matters

  • 🔢
    Clock Skew Immunity: Strictly incrementing integer counters prevent out-of-order message display across distributed timezones.
  • 🔄
    Client Gap Detection: If a mobile app misses sequence #13, it requests an instant delta sync automatically.
  • 📜
    Kafka Event Sourcing: Retained event log provides immutable auditability for enterprise compliance.

Reliability Flow Lifecycle

1. Ingress: Client sends frame via WSS
2. Sequence: MongoDB atomically allocates current_seq + 1
3. Commit: Event committed to persistent Kafka topic
4. Broadcast: NATS JetStream delivers to online clients (< 28ms)
5. Push Fallback: Dispatches to APNs/FCM only if user is offline
Atomic Monotonic Sequencing • Multi-Device Sync
